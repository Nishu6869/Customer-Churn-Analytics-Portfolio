# Customer Churn Analytics Portfolio

End-to-end customer churn analytics portfolio using Python and an interactive HTML KPI dashboard.

## Project roadmap
- **Task 1 — Data Quality & Exploratory Analysis:** completed in `Task-01-Data-Quality-EDA/`.
- **Task 2 — Business KPI Dashboard:** dashboard source uploaded in `docs/index.html`; GitHub Pages must be enabled from `main /docs` to publish the website.
- **Task 3 — Segmentation & Recommendation Model:** completed artifacts in `Task-03-Segmentation-Recommendation/`.
- **Task 4 — Executive Analytics Capstone:** next.

## Task 1
Data audit, cleaning, validation, EDA, data dictionary and summary.

## Task 2
Interactive dashboard with churn rate, retention rate, monthly revenue at risk, average tenure, and filters for contract type, tenure band and payment method.

## Task 3
Tenure-based segments, explainable heuristic risk scoring, customer-level score explanations and retention recommendations.

## Important limitations
The sample contains only 15 records. Findings are descriptive and not statistically conclusive. The Task 3 score is a transparent heuristic, not a trained or calibrated predictive model. Currency is not specified in the source.
